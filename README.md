# My Mini Tools Portfolio

这是一个包含几个我开发的小工具/应用的集合项目。
This repository contains a collection of small tools and applications I have developed.

## 项目列表 (Projects)

### 1. 记账工具 (Bill Manager)
一个用于管理和记录日常账单的小工具。

### 2. 财务管理 (Finance Manager)
用于财务数据统计和分析的管理系统。

### 3. 订单系统 (Sistema Pedidos)
一个用于处理和管理订单的系统前端与后端应用。

### 4. 超市比价器 (Supermarket Comparator)
用于比较不同超市商品价格的实用工具。

## 运行方式 (How to run)
每个项目都是独立的模块，你可以进入对应的文件夹并按照其内部的说明进行运行。大多数前端项目可以使用以下命令运行：

```bash
cd <project-folder>
npm install
npm run dev
```
